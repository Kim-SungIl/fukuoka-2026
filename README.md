# 후쿠오카 가족여행 2026

HOTEL IORI를 기준으로 짠 3박 4일 가족여행 가이드 (2026.10.02 – 10.05).
서버가 필요 없는 정적 페이지 한 장입니다.

- `index.html` — 페이지 전체 (CSS 인라인)
- `img/` — 지도 4장(OpenStreetMap 기반) + 사진 8장(Wikimedia Commons) + og 이미지

원본은 vinext + Cloudflare Workers 프로젝트이며, 이 폴더는 GitHub Pages 배포용으로 정적 렌더링한 결과물입니다.
